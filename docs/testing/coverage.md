# Coverage

Engineering target: at least 80% line coverage for relevant first-party application code. CI installs PCOV and runs `php artisan test --coverage --min=80`. PHPUnit includes `app/` and excludes the unused Laravel starter `app/Models/User.php`; vendor code and compiled assets are outside the source scope. A local Xdebug run before this exclusion reported 97.6% for `PortfolioController` and 89.3% overall (the unused starter User model accounted for uncovered lines). The exact CI-scoped report is enforced on every quality run; the target remains a guardrail, not a reason to add meaningless tests.
