# Accessibility

Implemented: semantic landmarks, skip link, text navigation, focus-visible styles, non-color status text, fluid responsive layouts, keyboard-operable native theme button, responsive content, reduced-motion CSS, useful link names, and page metadata. Theme choice respects manual control; initial theme defaults dark.

Before release, manually verify keyboard order, visible focus, screen-reader announcements, contrast in both themes, zoom to 200%, small viewport navigation, and real-browser reduced motion. Automated route tests are not an accessibility conformance audit; Lighthouse/WCAG scores are not claimed.
