# Content management

Content is version-controlled. Update project facts in `config/portfolio.php` only after checking source repositories and obtaining permission to disclose private details. Add articles as Markdown under `resources/content/articles/`, with YAML-like scalar front matter delimited by `---`; accepted keys are slug/title/description/date/status. Use a valid ISO date, lowercase-hyphen slug, and `status: published` only after editorial review. Any other status is excluded. Markdown is rendered through Laravel CommonMark; raw HTML handling follows the framework defaults. Laravel's configured locale and locale-derived HTML `lang` attribute provide a future localization entry point; current copy and content are English only, with no incomplete Portuguese translation. No admin UI or full CMS exists.
