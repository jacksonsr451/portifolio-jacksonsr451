# Getting started

Requirements: PHP 8.4+, Composer 2, Node 22+, npm, SQLite/PDO SQLite. PHP 8.4 is the effective minimum because the selected PHPUnit 13 development toolchain requires it. Follow root README. Verify with `composer test`, `composer lint`, `composer analyse`, and `npm run build`. `php artisan serve` runs the app; `npm run dev` provides Vite hot reload in a second terminal.
