# Security policy

Do not report vulnerabilities in public issues. Contact the repository owner privately through a verified security contact once one is configured. Until then, do not include sensitive details in public reports. No security service or private inbox is implied by this document.

Supported version: latest default-branch code. Security review includes dependency auditing, safe Markdown rendering, framework CSRF defaults for future state-changing forms, least-privilege CI, and secret exclusion. See `docs/security/`.
